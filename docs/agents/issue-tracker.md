# Issue Tracker

**Tracker:** Local markdown.

Issues live as files under `.scratch/<feature>/issues/` — one file per ticket, numbered from
`01` in dependency order (blockers first). See `.scratch/pdf-extraction/issues/` for the current
example.

No GitHub Issues workflow is configured (`gh` CLI isn't installed on the dev machine). Skills
like `to-tickets`, `triage`, `to-spec`, and `qa` should default to this local-markdown convention
for this repo rather than asking each time.

PRs as a request surface: off.
