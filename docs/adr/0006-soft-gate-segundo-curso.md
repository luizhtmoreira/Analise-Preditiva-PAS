# Soft Gate no segundo curso, não após o resultado

O Preditor é gratuito para o primeiro cálculo. O login é solicitado apenas quando o Aluno tenta adicionar um segundo curso ao Painel Multi-Curso.

Consideramos acionar o gate imediatamente após exibir o resultado do primeiro cálculo. Rejeitamos porque o Aluno ainda não experimentou o valor diferencial do produto logado — ele viu uma probabilidade, mas não entendeu o que ganha criando conta. Ao acionar no segundo curso, o gatilho coincide com o momento em que o Aluno já quer mais: ele usou o produto, viu que funciona, e está ativamente tentando expandir o uso. A proposta "crie conta para comparar vários cursos" tem contexto emocional real nesse ponto.

## Considered Options

- **Modal após N segundos**: descartado — interrompe antes de o Aluno terminar a tarefa, gera irritação.
- **Gate no primeiro cálculo (hard gate)**: descartado — bloqueia antes de o Aluno ver qualquer valor, aumenta abandono.
- **Gate após o resultado**: descartado — o Aluno viu o número mas não entendeu o que perde ao não criar conta.
